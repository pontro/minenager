📖 Setup Guide & Bot Commands Reference

⚡ 3-Step Setup Guide

  1. Go to Discord Developer Portal ➔ Create an Application.
  2. In the Bot tab:
    • Click Reset Token & copy it here.
    • Under Privileged Gateway Intents, enable Message Content Intent.
  3. In the OAuth2 ➔ URL Generator tab:
    • Select bot scope.
    • Select permissions: Send Messages, Embed Links, Read Message History.
    • Open the generated URL to invite the bot to your Discord server.
  4. In Discord: Right-click your channel ➔ Copy Channel ID and paste it above.

⌨️ Available Discord Commands

!turnon / !start [Admin] Start Server
!turnoff / !stop [Admin] Stop Server
!restart [Admin] Restart Server
!cmd <command> [Admin] Run MC Console Command
!status Check Status, RAM & Version
!metrics / !tps Live CPU %, RAM Usage & TPS
!players List Online Players & Avatars
