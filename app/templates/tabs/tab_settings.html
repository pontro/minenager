🌍 World Reset

Delete only the world save data (overworld world/, Nether, The End, player inventories, and advancements). Does NOT touch your server .jar, installed mods, or configuration. A fresh world will generate upon next startup.

⚠️ Danger Zone

Completely wipe all server data in /data/minecraft/ (mods, world, configuration, server .jar) to start from scratch. Backups in /data/backups/ will be preserved.
